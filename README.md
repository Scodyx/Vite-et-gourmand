# Vite & Gourmand

Application web de gestion et de commande de menus pour l'entreprise de traiteur Vite & Gourmand.

## Stack technique prévue

- Front-end : Angular
- Back-end : Java 21 et Spring Boot
- Base de données relationnelle : PostgreSQL
- Base de données non relationnelle : MongoDB
- Sécurité : Spring Security et JWT
- Documentation API : Swagger / OpenAPI

## Structure du projet

- frontend : application Angular
- backend : API Spring Boot
- database : scripts SQL et données initiales
- documentation : maquettes, diagrammes et documents du projet

## Organisation Git

- main : versions stables et déployables
- develop : intégration des fonctionnalités
- feature/* : développement des fonctionnalités
- fix/* : corrections
- docs/* : documentation
