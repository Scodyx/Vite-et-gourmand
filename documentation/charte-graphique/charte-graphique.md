# Charte graphique

Vite & Gourmand exprime une cuisine bordelaise chaleureuse, précise et contemporaine.

- Crème `#FBF7EF` et papier `#FFFDF8` : fonds.
- Brun `#402F27` : texte principal.
- Vert profond `#184F43` : actions et identité.
- Or `#B7863D` : accent.
- Terracotta `#A84F38` : repères secondaires.

Les titres utilisent Georgia (repli serif natif), les textes Inter/system-ui. Les boutons ont un libellé explicite, un fond vert et du texte blanc. Champs bordés, labels toujours visibles, cartes peu arrondies et espaces généreux.

Le focus comporte un contour doré de trois pixels. Le sens n’est jamais porté par la couleur seule ; les erreurs associent texte et bordure. Une seule balise `h1` structure chaque page, les images possèdent un texte alternatif et les mises en page basculent sur une colonne sous 800 px.

Les futures maquettes doivent réutiliser les variables CSS de `frontend/src/styles.scss` et vérifier les contrastes WCAG AA.
